# Getting Started

The canonical guide is [docs/getting-started.md](../getting-started.md).

Quick path:

```bash
npx sinapse-ai@latest install
npx sinapse-ai@latest status
npx sinapse-ai@latest doctor
```

Fresh no-flag installations configure Claude Code and Codex. Activate
`@sinapse-orqx` in Claude Code or `$snps` in Codex.
