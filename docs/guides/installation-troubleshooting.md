# Installation and Troubleshooting

The canonical installation path is:

```bash
npx sinapse-ai@latest install
```

Use the maintained guides:

- [Installation and updates](../installation/README.md)
- [Troubleshooting](../installation/troubleshooting.md)
- [npx cache](../installation/npx-cache.md)
- [Support](../../SUPPORT.md)

Do not execute remote diagnostic scripts through `curl | shell` or `irm | iex`.
Use the packaged `status` and `doctor` commands and inspect any proposed repair.
