# Framework Roadmap

The canonical public roadmap is [ROADMAP.md](../../ROADMAP.md).

Framework proposals are evaluated against executable governance, Claude
Code/Codex parity, safe installation and update behavior, cross-platform
support, security, and maintenance cost. Dates are not committed until work has
a validated scope, owner, and delivery plan.

Historical roadmap documents may remain in archived release material, but they
must not be interpreted as current commitments.
