# TypeSafe e aquisição UI/UX

Outcome: instalar e aplicar a skill oficial TypeSafe; absorver mecanismos de navegação e interface com evidência; usar Opus somente como pesquisa de mercado.

Fronteiras: aquisição de fontes, julgamento semântico tipado, revisão e recuperação por competência. Código controla orçamento, persistência, hashes e permissões. Julgamentos não autorizam publicação nem promoção de especialistas.

ASRs: um método de instalação e hash oficial; nenhum segredo em artefatos; um lote Jev sem retry e teto compartilhado US$0,05; nenhum estado Mobbin inferido contado como observado; nenhuma chamada Opus; preservar original e caminhos protegidos.

Decisão: skill Codex global via CLI oficial verificada, disponível para este projeto sem modificar a árvore original. Playground autenticado permite piloto sem criar credencial; integração automática continua exigindo chave local autorizada. Coleta de mecanismos textuais e locators, sem redistribuir acervo pago ou executar ações nos produtos de terceiros.

Alternativas rejeitadas: plugin Claude junto com CLI (duplicaria instalação); milhares de screenshots sem fluxo (não prova navegação); Opus API (fora do pedido); promoção por confiança Jev isolada (não prova qualidade de entrega).

Aceite: AC1–AC5 da story. Limites: no máximo uma tentativa paga por lote, três tentativas de reparo de instalação/validação, sem fan-out de modelos ou compras. Rollback somente arquivos desta execução com precondição de hash e backup; preservar mudanças concorrentes.

Transferência: uma interface própria de filtros e colunas, com exemplos fictícios e sem mídia copiada, verifica o resumo fiel, aplicação/cancelamento, vazio e teclado em desktop/390px/320px. Até três ciclos. Não comprova backend nem ganho geral.
