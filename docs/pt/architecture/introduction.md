# Introdução

> 🌐 **PT**

---

Este documento captura o estado atual do codebase do **SINAPSE**, servindo como a arquitetura de referência para o desenvolvimento da **Fase 1 do SINAPSE (MVP até o FR4)**. Ele descreve os padrões, componentes e tecnologias existentes sobre os quais as novas funcionalidades serão construídas.

## Escopo do Documento

Documentação abrangente do framework SINAPSE para servir como baseline para o MVP do SINAPSE, que inclui: Rebranding, Workflow de Setup de IDE, Camada de Memória (Chrome Brain v3) e o Meta-Agente `sinapse-developer`.
