# Visão Geral de Squads

Uma squad é uma equipe limitada por domínio, formada por agentes, tasks,
workflows e knowledge bases. O SINAPSE distribui 17 squads neste repositório.

```bash
node .codex/scripts/resolve-codex-agent.js --stats
```

Orquestradores roteiam; especialistas executam. No Claude Code, ative
`@animations-orqx`; no Codex, use `$sinapse-agent animations-orqx`. Quando o
domínio não estiver claro, use `@sinapse-orqx` ou `$snps`.
