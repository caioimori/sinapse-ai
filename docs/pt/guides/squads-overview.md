# Visao Geral de Squads

Uma squad e uma equipe limitada por dominio, formada por agentes, tasks,
workflows e knowledge bases. O SINAPSE distribui 17 squads neste repositorio.

```bash
node .codex/scripts/resolve-codex-agent.js --stats
```

Orquestradores roteiam; especialistas executam. No Claude Code, ative
`@animations-orqx`; no Codex, use `$sinapse-agent animations-orqx`. Quando o
dominio nao estiver claro, use `@sinapse-orqx` ou `$snps`.
