# Guia de Squads

O contrato atual de desenvolvimento e distribuição está no
[guia canônico](../../guides/contributing-squads.md).

Squads vivem em `squads/squad-<id>/`, usam `squad.yaml`, precisam de autoridade
distinta, pointers resolvíveis, testes, documentação e paridade Claude
Code/Codex. Exemplos históricos com marketplace, repositório separado,
`pack.yaml`, `manifest.yaml` ou `@squad:agent` não fazem parte do contrato atual.
