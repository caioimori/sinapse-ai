# Story 10.46 — Setup wizard SEMPRE pergunta idioma + LLM no install

## Story

**As a** primeiro-usuário rodando `npx sinapse-ai install` em qualquer ambiente interativo (Git Bash + Windows, PowerShell, macOS, Linux),
**I want** o instalador me perguntar idioma (PT/EN) e LLM provider (Claude Code / Codex / ambos) antes de gravar qualquer arquivo,
**so that** minha primeira impressão do framework reflita uma escolha minha — não defaults silenciosos `pt` + `claude-code` aplicados sem eu saber.

## Context

Bug P0 reportado por Caio em 2026-04-28. Diagnóstico realizado por sinapse-orqx confirmou: o wizard de setup (idioma + LLM) **existe e está implementado** em dois lugares (`bin/cli.js` inline e `packages/installer/src/wizard/index.js` modular), mas **nunca dispara** no fluxo real de `npx sinapse-ai install` por três bugs combinados.

**Bugs confirmados** (file:line):

1. **`bin/cli.js:262`** — `if (!process.stdin.isTTY) return 'claude-code'` pula o prompt de LLM. Em Git Bash + Windows + Node 24, `process.stdin.isTTY === undefined` (falsy), então o gate fecha silenciosamente e aceita `'claude-code'` como default.
2. **`bin/cli.js:330`** — mesma armadilha replicada no prompt de idioma. `if (!language) { language = 'pt'; if (process.stdin.isTTY) { ... } }` — se não for TTY, nem tenta perguntar.
3. **`bin/cli.js:574-578`** — quando `bin/cli.js` (entry canônico, registrado em `package.json:bin` como `sinapse-ai`) delega ao wizard modular mais rico em `packages/installer/src/wizard/index.js:484-521`, ele passa `quiet: true` hardcoded. O wizard modular tem prompts adicionais (user profile, project type, tech preset) que **nunca aparecem** por causa do quiet mode.
4. **`bin/cli.js:1462`** — `npx sinapse-ai` sem argumentos cai no comando `help` em vez de oferecer `install` na primeira execução. Reduz descoberta do fluxo correto.

**Por que ninguém pegou antes:** Install Matrix Gate A.5 (24/27 PASS) só validou "instalou sem erro", não "perguntou idioma e LLM". Nenhum AC anterior cobriu o prompt visualmente.

**Não é regressão da Story 10.44** (PR #114 removeu `bin/sinapse-cli`, bash script). O bug existe desde Stories 10.20 (idempotent upsert) + 10.33 (non-TTY handling).

**Severidade P0** — bloqueia v10.0.0 GA. Impacta diretamente primeira impressão do framework open-source.

## Acceptance Criteria

1. **Given** um usuário roda `npx sinapse-ai install` em terminal interativo (Git Bash Windows, PowerShell, bash macOS/Linux), **when** o instalador inicia, **then** o prompt de idioma (PT/EN) aparece visivelmente antes de qualquer escrita de arquivo.

2. **Given** o usuário escolheu um idioma, **when** o wizard avança, **then** o prompt de LLM provider (Claude Code / Codex / ambos) aparece visivelmente — mesmo em shells onde `process.stdin.isTTY` retorna `undefined` (caso conhecido: Git Bash + Windows + Node 24).

3. **Given** o instalador roda em ambiente verdadeiramente não-interativo (CI detectado por env var `CI=true`, `GITHUB_ACTIONS=true`, ou flag `--yes`/`npm_config_yes`), **when** o instalador inicia, **then** ele usa defaults `pt` + `claude-code` silenciosamente mas imprime warning visível: `INFO: ambiente nao-interativo detectado, usando defaults pt + claude-code (use --interactive pra forcar prompts)`.

4. **Given** a heurística de detecção de modo interativo, **when** avaliada, **then** ela usa multi-sinal: `process.stdin.isTTY || process.stdout.isTTY || (!process.env.CI && !process.env.GITHUB_ACTIONS && !process.env.npm_config_yes)` — não depende de `stdin.isTTY` sozinho.

5. **Given** o wizard inline em `bin/cli.js` já coletou `language` e `selectedLLM`, **when** delega ao wizard modular em `packages/installer/src/wizard/index.js`, **then** ele NÃO passa `quiet: true` hardcoded — passa os valores resolvidos e permite que prompts adicionais (user profile, project type) apareçam quando aplicável.

6. **Given** o usuário roda `npx sinapse-ai` sem argumentos numa pasta sem `.sinapse-ai/` instalado, **when** o CLI processa o comando vazio, **then** ele oferece `install` em vez de exibir `help` puro (preserva `help` quando já instalado ou explicitamente solicitado).

7. **Given** a test matrix de install, **when** executada, **then** existe um caso novo "fresh install Windows + Git Bash" que captura output e valida via assertion que strings como "Language", "Idioma", "LLM", ou equivalentes nos prompts aparecem no stdout/stderr antes da primeira escrita de arquivo em `~/.claude/`.

**Helper `detectInteractiveMode()` proposto:**
```js
function detectInteractiveMode() {
  if (process.env.CI === 'true') return false;
  if (process.env.GITHUB_ACTIONS === 'true') return false;
  if (process.env.npm_config_yes === 'true') return false;
  if (process.argv.includes('--yes') || process.argv.includes('-y')) return false;
  if (process.argv.includes('--non-interactive')) return false;
  if (process.argv.includes('--interactive')) return true;
  return Boolean(process.stdin.isTTY || process.stdout.isTTY);
}
```

**Não inventar libs:** continuar com `inquirer` já presente no `package.json`. NÃO adicionar nova dependency.
