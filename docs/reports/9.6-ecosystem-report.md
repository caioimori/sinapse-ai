## New CLI Capabilities

### `sinapse qa audit`
New subcommand for ecosystem quality auditing.

```bash
sinapse qa audit                    # Full ecosystem audit
sinapse qa audit -t workflows       # Audit workflows only
sinapse qa audit -t tasks           # Audit tasks only
sinapse qa audit -t kbs             # Audit knowledge bases only
sinapse qa audit -s squad-brand     # Audit specific squad
sinapse qa audit --json             # JSON output
sinapse qa audit --save-report      # Save to docs/reports/
sinapse qa audit --verbose          # Detailed output
```

### `sinapse qa` (existing, now registered in CLI router)
- `sinapse qa run` - Execute quality gate pipeline
- `sinapse qa run --layer=1` - Layer-specific
- `sinapse qa status` - Show gate status
