## Contrato do session-cache (v2) — fonte de verdade das 3 peças

`~/.claude/session-cache/{simpleHash(cwd)}.json`:

```json
{
  "version": 2,
  "agent": "developer",
  "squad": "design",
  "role": "imperator|orqx|specialist|null",
  "imperator": { "active": true, "ts": 1718560000 },
  "specialists": [ { "id": "developer", "label": "developer", "icon": "🤖", "ts": 1718560000 } ],
  "updated": "2026-06-16T12:00:00.000Z"
}
```

**Escrita (detector, UserPromptSubmit):** `@sinapse|@snps|@sinapse-orqx|@snps-orqx` → `imperator.active=true`, `role=imperator` (não entra em specialists). `@x-orqx` → `role=orqx`. Demais `@id` → push dedup em `specialists[]` (case-insensitive, cap 6, descarta mais antigo). `/ns:agents:nome` = `@nome`. `*exit`/`*reset` → zera. Fail-open.

**Leitura (statusline/painel, TTL 6h = 21600s):** `imperator` e `specialists` com `now-ts > 21600` tratados como inativos. Clear no Stop é a 1ª rede; TTL é a 2ª.
