## Bloqueios atuais (precisam de input/decisão)

1. **URL do curso ausente.** Preciso do link da plataforma/trilha.
2. **Restrição de rede do ambiente.** Esta sessão remota só acessa `github.com`
   (allowlist). Plataformas de curso (Hotmart, Udemy, site próprio, etc.) provavelmente
   serão bloqueadas via fetch direto. Verificar host quando a URL existir.
3. **Transcrição de vídeo ≠ fetch de texto.** Não dá para "transcrever vídeo" só lendo a
   página. Precisamos de uma destas fontes:
   - legendas/transcrição já disponíveis (exportáveis como texto), OU
   - acesso ao áudio/vídeo para transcrição (requer ferramenta de STT + o arquivo), OU
   - o usuário fornece os arquivos/legendas.
