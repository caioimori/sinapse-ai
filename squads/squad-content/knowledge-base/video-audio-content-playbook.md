# Video & Audio Content Playbook

> Fonte: MS-008 Content Strategy Research (2026-04-07). Dados de plataformas verificados.

---

## 1. YouTube Strategy

YouTube e o 2o maior mecanismo de busca do mundo. ~2.5-2.6 bilhoes de usuarios ativos mensais em 2025, ~2.85 bilhoes em 2026.

**Estrategia de crescimento em fases:**

```
Fase 1 — Foundation (0-1K subscribers)
├── Definir nicho especifico
├── Publicar 2-3 videos/semana
├── Focar em search content (how-tos, tutoriais)
├── Titles e thumbnails otimizados para CTR
└── Objetivo: encontrar o formato que funciona

Fase 2 — Growth (1K-10K)
├── Manter cadencia
├── Expandir para browse/suggested content
├── Series e playlists
├── Community engagement (comentarios, community posts)
└── Objetivo: crescimento sustentavel

Fase 3 — Scale (10K-100K+)
├── Mix de search + browse + subscriber content
├── Colaboracoes com outros criadores
├── Content diversification (Shorts, livestreams)
├── Monetizacao (AdSense, sponsorships, products)
└── Objetivo: autoridade no nicho
```

## 2. Video SEO para YouTube

| Fator | Otimizacao |
|-------|-----------|
| **Title** | Keyword no inicio, < 60 chars, ganchos de curiosidade |
| **Description** | 200+ palavras, keyword nos primeiros 100 chars, timestamps, links |
| **Tags** | 5-15 tags relevantes (keyword principal + variacoes + topico amplo) |
| **Thumbnail** | Custom, alto contraste, face expressiva, texto curto |
| **Chapters** | Timestamps no formato 0:00 na descricao (gera key moments no Google) |
| **Cards & End Screens** | Link para videos relacionados (aumenta session time) |
| **Closed Captions** | Upload de SRT (nao apenas auto-generated) |
| **Filename** | keyword-no-filename.mp4 (antes do upload) |
| **First 48h** | Periodo critico — impressoes iniciais determinam alcance |

**Sinais de ranking YouTube:**

| Sinal | Peso | Como Otimizar |
|-------|------|---------------|
| Watch Time | Muito Alto | Loops de retencao, pattern interrupts, manter ritmo |
| CTR (Thumbnail + Title) | Alto | Thumbnail forte, titulo com curiosity gap |
| Session Time | Alto | Conteudo que leva a mais videos, playlists |
| Comments | Medio | CTA para comentar, perguntas no video |

## 3. Short-Form Video (Reels, TikTok, Shorts)

**Dados de mercado (2026):**
- TikTok: ~1.9 bilhoes de usuarios ativos mensais
- YouTube Shorts: 200+ bilhoes de views diarias (2025), vs 70 bilhoes em 2024
- Instagram Reels: maior formato de crescimento da plataforma

**A regra dos 3 segundos:** 65% dos viewers decidem nos primeiros 3 segundos se continuam assistindo.

**Tipos de Hook para Short-Form:**

| Tipo de Hook | Exemplo |
|-------------|---------|
| Controversial statement | "Content marketing esta morto. Aqui esta o que funciona." |
| Question | "Voce sabe por que 90% dos blogs nao geram leads?" |
| Number/Stat | "Essa tecnica triplicou nosso trafego em 30 dias" |
| Before/After | "Minha newsletter tinha 200 inscritos. Hoje tem 50.000." |
| Tutorial promise | "Em 30 segundos voce vai aprender a escrever headlines 3x melhores" |
| Pattern interrupt | Comeca com acao inesperada, corte rapido, som diferente |

**Producao de short-form:**
- Formato vertical (9:16), 1080x1920px
- Legendas em tela (85% assiste sem som)
- Cortes rapidos (2-3 segundos entre transicoes)
- Texto overlay para pontos-chave
- Musica trending (quando aplicavel ao contexto da marca)
- Chamada final (follow, compartilha, comenta)

## 4. Tipos de Video Content

| Tipo | Producao Necessaria | Uso Ideal |
|------|---------------------|-----------|
| **Talking Head** | Camera + mic + iluminacao | Opiniao, analise, storytelling |
| **Screen Share** | Screen recording + voiceover | Tutoriais, demonstracoes |
| **B-Roll Narrative** | Camera + B-roll + voiceover | Documentarios, case studies |
| **Interview** | 2+ cameras + mics | Podcasts video, expert content |
| **Animation** | Motion graphics software | Explainers, conceitos abstratos |
| **Hybrid** | Mix de formatos | Maior engajamento, variedade visual |

## 5. Workflow de Producao de Video

```
Pre-Producao:
├── Briefing / Script / Outline
├── Shot list (B-roll necessario)
├── Locacao / Setup (iluminacao, audio, camera)
├── Teleprompter ou bullet points
└── Thumbnail planejada

Producao:
├── Gravar intro/hook primeiro (energia maxima)
├── Gravar corpo em blocos (facilita edicao)
├── Gravar B-roll separadamente
├── Gravar CTA/outro
└── Verificar audio e enquadramento

Pos-Producao:
├── Rough cut (montar estrutura)
├── Fine cut (cortar pausas, erros, tangentes)
├── Color grading
├── Audio mixing (nivelamento, musica, SFX)
├── Motion graphics (lower thirds, texto)
├── Thumbnail design
├── Export em resolucoes necessarias
└── Upload + otimizacao (title, desc, tags)
```

## 6. Podcasting Strategy

Podcast e o formato mais eficaz para construcao de autoridade profunda. Diferente de um blog post (5 minutos de leitura), um podcast ocupa 30-60 minutos da atencao do ouvinte.

**Mercado global (2025-2026):**
- ~584 milhoes de ouvintes globais em 2025, projetados para 619 milhoes em 2026
- Mercado global: USD 30.7 bilhoes (2024), projetado para USD 131 bilhoes ate 2030 (CAGR 27%)
- Brasil: 2o maior mercado de podcasts do mundo (apos EUA), com ~44% da populacao ouvindo semanalmente

**Estrategia de podcast em 4 dimensoes:**

```
1. POSICIONAMENTO
   ├── Nicho especifico (nao "marketing" — mas "content strategy para SaaS B2B")
   ├── Formato (interview, solo, panel, narrative)
   ├── Cadencia (semanal e o padrao — consistencia > frequencia)
   ├── Duracao (30-60min para conversas, 15-20min para solo)
   └── Tom e personalidade do host

2. PRODUCAO
   ├── Equipamento minimo: mic USB decente (Blue Yeti, Rode NT-USB Mini)
   ├── Software de gravacao: Riverside.fm, Zencastr (remoto), Audacity (local)
   ├── Edicao: Descript (edita audio como texto), Adobe Podcast (AI enhancement)
   ├── Hosting: Spotify for Podcasters, Buzzsprout, Podbean, Transistor
   └── Arte: Capa 3000x3000px, consistente com marca

3. DISTRIBUICAO
   ├── RSS feed → todos os diretorios automaticamente
   ├── Spotify, Apple Podcasts, YouTube Music, Amazon Music
   ├── YouTube (versao video do podcast = 2x audiencia)
   ├── Social clips (cortes de 30-60s para Reels/TikTok)
   └── Newsletter (show notes + link do episodio)
   
   NOTA: Google Podcasts foi descontinuado em 2024, migrado para YouTube Music.

4. CRESCIMENTO
   ├── Convidados com audiencia propria (cross-pollination)
   ├── Guest appearances em outros podcasts
   ├── SEO das show notes
   ├── Social media promotion
   └── Comunidade de ouvintes (Discord, Telegram)
```

## 7. Monetizacao de Podcast

| Modelo | Descricao | Quando Aplicar |
|--------|-----------|---------------|
| **Sponsorship** | Marcas pagam por mencao (pre/mid/post-roll) | 5.000+ downloads/episodio |
| **Premium Content** | Episodios exclusivos para assinantes | Audiencia engajada |
| **Afiliados** | Comissao por vendas via link/codigo | Desde o inicio |
| **Produtos proprios** | Curso, consultoria, comunidade | Apos estabelecer autoridade |
| **Doacoes** | Patreon, Apoia.se, Buy Me a Coffee | Comunidade fiel |
| **Eventos** | Lives pagas, workshops, meetups | Audiencia local/engajada |

## 8. Show Notes SEO

Show notes sao paginas de texto que acompanham cada episodio. Com otimizacao correta, geram trafego organico duradouro.

**Componentes de show notes eficazes:**
- Titulo com keyword primaria
- Resumo do episodio (200-400 palavras)
- Timestamps principais (chapters)
- Transcricao completa ou parcial
- Links para fontes mencionadas
- Bio do convidado (com links)
- CTAs (subscribe, newsletter, produto)
- Schema markup (Podcast, Episode)
