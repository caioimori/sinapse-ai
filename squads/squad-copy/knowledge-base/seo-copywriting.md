# SEO Copywriting

> Fonte primaria: MS-008 (secao 6) — SEO Content.
> Copywriting que converte para humanos E rankeia para motores de busca.
> Principio: Search intent antes de keywords. Humanos antes de algoritmos.

---

## 1. O Fundamento: Search Intent Mapping

Antes de escrever uma palavra de SEO copy, identifique o INTENTO de busca.
Copy que nao atende ao intent nao ranka — mesmo com tecnica impecavel.

| Intent | O que o Usuario Quer | Copy Approach | Formato Ideal |
|--------|---------------------|---------------|---------------|
| **Informacional** | Aprender algo | Educar — fornecer resposta completa | Blog post, guia, FAQ |
| **Navegacional** | Encontrar um site/marca especifico | Nao e target de SEO content | N/A |
| **Comercial** | Comparar antes de comprar | Comparar, avaliar, recomendar | Comparativo, review, listicle |
| **Transacional** | Realizar uma acao (comprar, se inscrever) | Converter — proposta de valor + CTA | Landing page, pagina de preco |

**Regra de ouro:** Escreva para o intent, depois otimize para keywords.
Copy para intent errado = bounce alto = sinal negativo para o Google.

## 2. Anatomia de Copy SEO-Friendly

### Headline (Title Tag)
- Inclui keyword primaria — de preferencia no inicio
- < 60 caracteres (60-70 na SERP desktop)
- Hook que gera clique — mesmo que nao seja o #1
- Formula: "[Keyword] + [Beneficio/Angulo]" ou "[N] + [Keyword] + [Resultado]"

**Exemplo:**
- Keyword: "copywriting formulas"
- Title: "11 Formulas de Copywriting que Vendem (Com Exemplos Reais)"

### Meta Description
- < 160 caracteres
- Inclui keyword (o Google grifa em negrito)
- CTA implicito ou explicito
- Complementa o title — nao repete
- Formula: "[Beneficio principal] + [detalhe especifico] + [CTA soft]"

**Exemplo:**
- Meta: "Aprenda as formulas de copywriting mais testadas da historia — AIDA, PAS, BAB e mais. Com exemplos reais e quando usar cada uma."

### H1 (Headline Principal)
- Deve incluir a keyword primaria
- Pode ser igual ao title tag ou variacao
- Uma por pagina

### H2s (Subheadings)
- Incluem keywords secundarias e variantes
- Ajudam o Google a entender a estrutura topica
- Respondem perguntas especificas (People Also Ask)
- Cada H2 deve ser uma promessa de valor para o leitor

### Paragrafos de Abertura (primeiros 100-150 palavras)
- Inclui keyword primaria nos primeiros 100 caracteres
- Responde a query imediatamente (nao deixa o leitor esperando)
- Hook editorial — motivo para continuar lendo
- Sinaliza ao Google do que trata a pagina

## 3. E-E-A-T — Experiencia, Expertise, Autoridade, Confiabilidade

Google usa E-E-A-T como criterio central de qualidade de conteudo.
O primeiro "E" (Experience) foi adicionado em dezembro de 2022.

| Fator | Como Demonstrar no Copy |
|-------|------------------------|
| **Experience** | Escreva com base em experiencia propria — "testei isso por X meses", dados proprios, screenshots reais |
| **Expertise** | Bio do autor com credenciais, publicacoes, portfolio, anos de experiencia |
| **Authoritativeness** | Cite fontes respeitadas, mencione estudos, dados de pesquisa — nao apenas opinion |
| **Trustworthiness** | HTTPS, politica de privacidade, data de atualizacao, fontes citadas, nenhuma claim sem prova |

**Copy techniques para E-E-A-T:**
- Adicione data de atualizacao ("Ultima atualizacao: abril 2026")
- Cite estudos e dados com links para as fontes originais
- Inclua bio do autor com link para perfil profissional
- Use "Testei isso pessoalmente" ao inves de "Dizem que..."
- Adicione dados proprios, screenshots, resultados mensuraveis

## 4. Featured Snippets — Posicao Zero

Featured snippets sao trechos que o Google exibe diretamente na SERP antes dos resultados organicos.
Conquistar um featured snippet pode aumentar CTR em 20-30%.

### Tipos e Como Otimizar

| Tipo | Formato | Formula de Copy |
|------|---------|----------------|
| **Paragrafo** | Resposta em 40-60 palavras | Heading com a pergunta + paragrafo de resposta direta |
| **Lista** | Lista ordenada ou nao | Heading + bullets/numerados claros e concisos |
| **Tabela** | Dados comparativos | Tabela HTML bem formatada com headers |
| **How-to** | Passos numerados | H2 "Como [X]" + steps numerados em H3 |

### Template para Paragraph Snippet
```
H2: O que e [Keyword]?

[Keyword] e [definicao em 40-60 palavras que responde diretamente].
[Adicione contexto especifico, por que importa, ou numero relevante].
```

### Template para List Snippet
```
H2: [As X] [Keyword] [para/que/em]?

- Item 1 (com 1-2 frases de contexto)
- Item 2
- Item 3
[...]
```

## 5. Semantic SEO — Escrevendo para Topicos, Nao Keywords

O Google de 2025-2026 entende topicos, entidades e relacoes semanticas — nao apenas keyword matching.
Copie que usa semantica rica ranka melhor e e mais lida.

### Cobertura de Entidades
Todo artigo sobre um topico deve mencionar as entidades relacionadas que o Google espera ver.
Artigo sobre "copywriting formulas" deve mencionar: AIDA, David Ogilvy, Dan Kennedy, PAS, Eugene Schwartz, headline, CTA, conversao, persuasao.

**Como descobrir entidades esperadas:**
1. Analise os top-5 resultados rankeados para sua keyword
2. Identifique entidades/termos que TODOS mencionam
3. Garanta cobertura dessas entidades no seu artigo

### NLP Optimization
- Use linguagem natural — variantes e sinonimos, nao a keyword repetida mecanicamente
- Responda as "People Also Ask" — cada PAA e uma secao potencial com featured snippet
- Coocorrencias semanticas: palavras que o Google espera ver juntas com sua keyword

### Pillar/Cluster Model (HubSpot)
Organiza conteudo em torno de topicos, nao keywords individuais.

```
PILLAR PAGE: "Guia Completo de Copywriting" (3.000-10.000 palavras)
    ↕ link bidirec.
CLUSTER 1: "Formulas de Copywriting" ← link para/do pillar
CLUSTER 2: "Headlines que Convertem" ← link para/do pillar
CLUSTER 3: "Email Copywriting" ← link para/do pillar
CLUSTER 4: "Copy para Ads" ← link para/do pillar
CLUSTER 5: "Landing Page Copy" ← link para/do pillar
```

**Resultado comprovado:** HubSpot reportou 3x mais crescimento de trafego em topic clusters vs. conteudo nao-clusterizado.

## 6. Readability — Escrevendo para Humanos Primeiro

**Flesch-Kincaid ideal para conteudo web:** Grade 7-8 (compreensivel por aluno de 12-13 anos).
Isso nao significa simplista — significa claro.

### Regras de Readability para SEO
- Frases: < 25 palavras (meta), < 20 palavras para partes criticas
- Paragrafos: < 5 linhas (web), 3 linhas e ideal
- Subheadings: a cada 300-400 palavras
- Bullets: quando ha 3+ itens na mesma categoria
- Bold: conceitos-chave, dados importantes, CTAs inline
- Voz ativa: "fizemos" em vez de "foi feito por nos"
- Palavras simples: "usar" em vez de "utilizar", "mostrar" em vez de "demonstrar"

### Estrutura de Introducao Ideal
```
[Frase 1] Hook — afirmacao contraintuitiva, numero, ou promessa
[Frase 2] Contexto — por que isso importa agora
[Frase 3] Keyword natural — a query respondida em linguagem natural
[Frase 4-5] O que o leitor vai aprender neste artigo
```

## 7. Content Decay e Refresh Strategy

**Content decay:** Perda gradual de trafego por desatualizacao, novos competidores, mudancas de intent.
20% do esforco editorial deve ir para refresh — e quase sempre mais eficiente que criar do zero.

### Quando Fazer Refresh

| Urgencia | Trigger | Acao |
|---------- |---------|------|
| Imediata | Dados factuais errados, informacoes desatualizadas | Atualizar imediatamente |
| Alta | Queda > 30% trafego, perdeu featured snippet | Refresh em 2 semanas |
| Media | Queda 15-30%, novo conteudo melhor nos concorrentes | Refresh em 30 dias |
| Baixa | Conteudo ok mas pode ser melhorado | Proximo ciclo trimestral |

### Refresh Checklist
```
[ ] Dados e estatisticas atualizados para 2025/2026
[ ] Novas secoes adicionadas (subtopicos emergentes)
[ ] H2s revisados para capturar novos PAAs
[ ] Internal links atualizados
[ ] Meta title e description otimizados
[ ] Data de publicacao atualizada (se mudancas substanciais)
[ ] Featured snippet recapturado com templates de snippet
[ ] Novos exemplos e cases de 2024-2026
```

## 8. SEO Copy Checklist Pre-Publicacao

```
KEYWORD OPTIMIZATION:
[ ] Keyword primaria no H1, primeiros 100 chars, e 2-3 vezes no body
[ ] Keywords secundarias distribuidas naturalmente
[ ] Semantica rica — entidades relacionadas presentes
[ ] Sem keyword stuffing (nunca force — leitura natural primeiro)

STRUCTURE:
[ ] Title tag < 60 chars, inclui keyword, tem hook
[ ] Meta description < 160 chars, inclui keyword + CTA
[ ] H1 unico com keyword
[ ] H2s com keywords secundarias e PAAs respondidas
[ ] Introducao com keyword nos primeiros 100 palavras

E-E-A-T:
[ ] Experiencia de primeira mao demonstrada
[ ] Fontes autoritativas citadas com links
[ ] Data de publicacao/atualizacao visivel
[ ] Bio do autor com credenciais

FEATURED SNIPPETS:
[ ] Perguntas no formato de H2/H3
[ ] Resposta direta em 40-60 palavras logo apos a pergunta
[ ] Lists formatadas corretamente para snippet
[ ] Tabelas com headers para snippet de tabela

LINKS:
[ ] 3-5 internal links para conteudo relacionado
[ ] 2-3 external links para fontes autoritativas
[ ] Anchor text descritivo (nao "clique aqui")

READABILITY:
[ ] Paragrafos < 5 linhas
[ ] Subheadings a cada 300-400 palavras
[ ] Voz ativa predominante
[ ] Frases curtas (< 25 palavras media)
```
