# squad-artdir — Art Direction for Conversion

Art direction focused on retention and conversion. Every pixel carries behavioral intent.

## The 7 Pillars

1. Visual Hierarchy & Controlled Attention
2. Psychologically Intentional Color System
3. Typography as Identity Signal
4. Motion as Kinesthetic Narrative
5. Information Architecture for Retention
6. Visual Persuasion via CRO Patterns
7. Layout & Spacing as Cognitive Breathing

## Non-negotiable Rules

1. Every aesthetic decision MUST cite a psychological principle
2. Performance > beauty (motion that lags kills conversion)
3. Accessibility > cinema (always fallback for prefers-reduced-motion)
4. Mobile-first, scale to desktop
5. Copy is design (microcopy, CTA labels, placeholders are visual decisions)
6. Never clone without understanding which trigger each element activates
7. Measurable or not done (every delivery has impact hypothesis)
