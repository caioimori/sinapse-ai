# Instructional Design Frameworks

Reference guide for selecting and applying the right framework for each course context.

---

## Framework Comparison Table

| Framework | Best For | Key Steps | Output |
|-----------|----------|-----------|--------|
| **ADDIE** | Full course builds, corporate training | Analyze → Design → Develop → Implement → Evaluate | Complete course with evaluation loop |
| **SAM** | Iterative/agile course builds | Preparation → Iterative Design → Iterative Development | Rapid prototype cycles |
| **Bloom's Taxonomy (Revised)** | Writing objectives, assessments | Remember → Understand → Apply → Analyze → Evaluate → Create | Verb-mapped learning objectives |
| **Gagné's 9 Events** | Single lesson/module design | 9 instructional events sequence | Structured lesson with measurable outcome |
| **Backward Design (UbD)** | Outcome-first curriculum | Identify outcomes → Assessments → Learning activities | Aligned curriculum map |
| **Competency-Based Design** | Vocational/professional training | Define competency → Break into skills → Assess mastery | Competency-verified learner |
| **Microlearning** | Busy professionals, mobile learners | Chunk → Focus → Reinforce | 3–10 min lesson units |
| **Spaced Repetition** | Retention-heavy content | Schedule review intervals | Spaced review system |
| **Dick & Carey** | Systematic, defense/corporate | 10-step linear model | Tightly sequenced instruction |

## ADDIE — Step-by-Step

| Phase | Questions to Answer | Key Deliverable |
|-------|---------------------|-----------------|
| **Analyze** | Who is the learner? What problem are we solving? What gaps exist? | Learner profile + needs analysis |
| **Design** | What are the outcomes? What sequence? What assessments? | Curriculum map + assessment plan |
| **Develop** | What content, materials, activities? | Lessons, workbooks, videos |
| **Implement** | How is it delivered? What platform? | Live or async course |
| **Evaluate** | Did learners achieve outcomes? What improves? | Feedback report + iteration plan |

## Bloom's Taxonomy — 6 Levels

| Level | Cognitive Skill | Action Verbs | Assessment Type |
|-------|----------------|--------------|-----------------|
| 1 — Remember | Recall facts | List, define, identify | Multiple choice, fill-in |
| 2 — Understand | Explain in own words | Summarize, describe, explain | Short answer, paraphrase |
| 3 — Apply | Use in new situations | Solve, use, execute, implement | Case study, exercise |
| 4 — Analyze | Break into parts | Compare, differentiate, examine | Breakdown exercise |
| 5 — Evaluate | Make judgements | Critique, justify, assess | Rubric-based review |
| 6 — Create | Produce new work | Design, build, compose | Project, portfolio |

**Rule:** Write all learning objectives starting with a Bloom's action verb. Match assessment type to the level.

## Gagné's 9 Events of Instruction

| Event | Purpose | Example |
|-------|---------|---------|
| 1. Gain attention | Activate focus | Surprising statistic, story, question |
| 2. State objectives | Set expectations | "By the end, you'll be able to..." |
| 3. Stimulate recall | Connect prior knowledge | "You already know X. Now we'll add Y." |
| 4. Present content | Teach the concept | Video, text, demo |
| 5. Provide guidance | Scaffold learning | Worked example, template |
| 6. Elicit performance | Practice | Exercise, quiz |
| 7. Provide feedback | Correct + reinforce | Answer key, comments |
| 8. Assess performance | Measure outcome | Test, project submission |
| 9. Enhance retention | Transfer to real life | Action plan, journaling prompt |

## Backward Design (Wiggins & McTighe)

1. **Identify desired results** — What will students know/do/be?
2. **Determine acceptable evidence** — How will you know they got it? (assessment first)
3. **Plan learning experiences** — What activities lead to that evidence?

**When to use:** Whenever there's a risk of teaching content that doesn't connect to real outcomes.

## Microlearning

- **Unit size:** 3–10 minutes per lesson
- **One concept per unit** — no cramming
- **Mobile-first format** — works on any device
- **Reinforcement:** Pair with spaced repetition
- **Best for:** Skill-based, compliance, product training

---

## Spaced Repetition

| Interval | Review Timing |
|----------|--------------|
| First review | 1 day after learning |
| Second review | 3 days later |
| Third review | 7 days later |
| Fourth review | 21 days later |
| Long-term | Monthly |

**Implementation:** Embed recap quizzes at module start. Use "Previously..." recaps. Assign journaling prompts.

## SAM — Successive Approximation Model

Developed by Michael Allen as an agile alternative to ADDIE. Built for speed and iteration.

**3 phases:**

| Phase | Steps | Duration |
|-------|-------|---------|
| **Preparation** | Information gathering, performance analysis | 1–3 days |
| **Iterative Design** | Savvy Start workshop → design prototype → review cycle | 1–2 weeks |
| **Iterative Development** | Alpha → Beta → Gold releases | 2–8 weeks |

**When to use SAM over ADDIE:**
- Tight deadlines (weeks, not months)
- Stakeholders need to see something fast
- Subject matter is evolving/uncertain
- Team is experienced with instructional design

**Savvy Start:** 1–2 day kickoff with stakeholders + SMEs. Output: rough prototype of 3–5 key interactions, content skeleton, visual theme.

## Competency-Based Design (CBD)

Structures learning around observable, measurable competencies rather than content coverage.

**Core principle:** "You pass when you can demonstrate the skill, not when you've watched the video."

**5-step CBD process:**

1. **Define the competency** — State what the learner must be able to DO (behavior + condition + standard)
2. **Identify sub-skills** — Decompose the competency into enabling skills (Gagne's learning hierarchy)
3. **Sequence from prerequisite to terminal** — Build the skill ladder
4. **Design mastery assessments first** — How will you verify competency?
5. **Build learning experiences to fill gaps** — Only teach what addresses a gap

**Competency statement formula:**
> "[Action verb] [object] [condition] to [standard of performance]"
> Example: "Classify accounting transactions by IFRS category using the CPC chart of accounts with 90% accuracy"

**When to use CBD:**
- Professional certifications (CRC, OAB, CPA)
- Corporate training with verifiable outcomes
- Vocational courses (accounting, law, healthcare)
- Any course where employers/clients judge learner output

**CBD vs. Traditional design:**

| Dimension | Traditional | Competency-Based |
|-----------|-------------|-----------------|
| Passes by | Time in course | Demonstrated skill |
| Pace | Fixed (class schedule) | Variable (when mastery achieved) |
| Failure means | Redo the unit | Keep practicing until mastery |
| Assessment purpose | Rank learners | Verify readiness |

## Bloom's Taxonomy — Revised (Anderson & Krathwohl, 2001)

The original Bloom (1956) used nouns. The 2001 revision uses **action verbs** and changes the top two levels.

| Level | Cognitive Process | Key Action Verbs | Assessment Type |
|-------|-----------------|------------------|-----------------|
| 1 — Remember | Retrieve from memory | list, identify, recall, recognize, name, define | Multiple choice, fill-in |
| 2 — Understand | Construct meaning | explain, summarize, classify, compare, interpret | Short answer, paraphrase |
| 3 — Apply | Execute in new context | solve, use, demonstrate, execute, implement | Case exercise, simulation |
| 4 — Analyze | Break into components | differentiate, organize, attribute, examine, deconstruct | Breakdown exercise, analysis |
| 5 — Evaluate | Make judgements | critique, assess, justify, defend, prioritize | Rubric-based review, debate |
| 6 — Create | Produce original work | design, construct, produce, plan, compose | Project, portfolio, capstone |

**Critical change from original:** "Synthesis" became "Create" (moved to top). "Evaluation" moved to level 5.

**Rule for course design:**
- Modules 1–2: focus on Remember/Understand
- Modules 3–5: push to Apply/Analyze
- Final project: must reach Evaluate or Create

**Bloom's for domain-specific courses:**

| Course Type | Minimum Target Level | Example |
|-------------|---------------------|---------|
| Accounting fundamentals | Apply (3) | "Calculate EBITDA from a real DRE" |
| Legal analysis | Analyze (4) | "Identify applicable legal principles in a case" |
| Compliance training | Apply (3) | "Fill out SPED-ECD correctly" |
| Strategic advisory | Evaluate (5) | "Recommend the optimal tax regime for this business" |

## Active Learning Strategies

Active learning produces 2× better retention than passive lecture (Freeman et al., 2014 meta-analysis, PNAS).

### Flipped Classroom

**Traditional:** Lecture in class → homework at home
**Flipped:** Consume content at home → practice/apply in live session

**Implementation for online courses:**
1. Assign async video/reading before each live session
2. Live session = 80% exercises, 20% Q&A
3. Pre-session quiz to verify content was consumed
4. Post-session assignment to transfer learning

**Works well for:** Cohort-based courses, corporate training, anything with a live component

### Problem-Based Learning (PBL)

Present an ill-structured problem → learners discover what they need to solve it.

**5-step PBL cycle:**
1. Present problem (real-world, messy, no single answer)
2. Learners identify what they know vs. what they need
3. Self-directed research/learning phase
4. Reconvene to apply new knowledge to problem
5. Debrief: what did we learn? What would we do differently?

**Example for accounting course:**
> "You're the controller for a Simples Nacional company that just hit R$4,5M in revenue. The partners want to know: should they stay in Simples or migrate to Lucro Presumido? What do you need to analyze?"

### Case Method (Harvard Case)

Present a real decision scenario. Learners analyze, debate, and decide.

**Case structure:**
1. Situation overview (who, what, when)
2. The decision point (what must be decided, by when)
3. Available data (financial, legal, operational)
4. Discussion questions

**Rule:** The case does not tell learners what the right answer is. The discussion is the learning.

**Best for:** Business law, accounting strategy, compliance, corporate governance

### Think-Pair-Share

Simple active structure for live sessions:
1. Pose a question or problem (1–2 min thinking solo)
2. Pairs discuss (2–3 min)
3. Pairs share with group (5–10 min discussion)

**Best for:** Breaking up long lectures, testing comprehension before moving on
