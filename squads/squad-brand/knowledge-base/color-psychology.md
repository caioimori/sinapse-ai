# Color Psychology — Knowledge Base

## Significados Universais

### Nuances Brasileiras
- **Verde e amarelo:** Associacao nacional forte. Usar com cautela fora de contexto patriotico — pode parecer "selecao" ou "politico."
- **Roxo:** Historicamente associado a luto em algumas regioes. Nubank ajudou a ressignificar positivamente.
- **Azul e branco:** Percebidos como "limpos" e "confiaveis" — dominam o setor financeiro brasileiro (Itau, Bradesco, BB).

### Sistemas de Cor (Especificacoes Tecnicas)
- **Pantone (PMS):** Sistema spot para impressao. Pantone 186 C = vermelho Coca-Cola (identico em Tokyo, Sao Paulo ou Nova York)
- **CMYK:** Para impressao offset. Conversao de Pantone para CMYK pode perder precisao.
- **RGB/HEX:** Para digital. Brand guidelines devem especificar HEX exatos.
- **HSL/HSB:** Para interfaces digitais modernas. Facilita criacao de variantes (lighter, darker).

## Harmonias Cromaticas

- **Complementar:** cores opostas no circulo (max contraste, ex: azul↔laranja)
- **Analogo:** cores vizinhas (harmonia suave, ex: azul-verde-ciano)
- **Triada:** 3 cores equidistantes (vibrante, equilibrado)
- **Split-complementary:** 1 cor + 2 adjacentes ao complementar (contraste com menos tensao)
- **Monocromatico:** 1 cor em diferentes luminosidades (elegante, coeso)

## Regra 70/25/5
- **70%** cor primaria (backgrounds, areas grandes)
- **25%** cor secundaria (secoes, cards, complementos)
- **5%** cor acento (CTAs, highlights, elementos interativos)

## Color-blind Safe
- Nunca depender APENAS de cor para informacao
- Usar icones/shapes alem de cor (check verde + icone check)
- Testar: protanopia (8% homens), deuteranopia (6% homens), tritanopia (raro)
- Ferramentas: Stark plugin, Sim Daltonism, Chrome DevTools
