# Research Synthesis Frameworks

> Frameworks para sintetizar múltiplas pesquisas, conectar descobertas cross-domain e transformar dados dispersos em inteligência acionável. Extraído de MS-009 e práticas do squad-research.

## O Problema da Síntese

Pesquisa fragmentada é pesquisa desperdiçada. Quando múltiplos agentes pesquisam em paralelo (wave-based approach), o valor real emerge na síntese:

- Cada fonte diz algo verdadeiro **sobre sua janela**
- A síntese revela o **padrão que conecta as janelas**
- O insight cross-domain é sempre mais valioso que achados isolados

**Anti-padrão crítico:** "Colocar relatórios lado a lado e chamar de síntese." Síntese real é transformativa — cria conhecimento que não existia em nenhuma fonte individual.

## Framework 1: Meta-Síntese Qualitativa

Para integrar achados de múltiplas pesquisas qualitativas sobre o mesmo tema.

### Processo
1. **Levantamento:** Listar todas as pesquisas qualitativas relevantes
2. **Avaliação:** Avaliar qualidade de cada estudo (rigor metodológico, relevância)
3. **Extração:** Retirar temas e conceitos-chave de cada pesquisa
4. **Tradução:** Comparar como cada pesquisa descreve o mesmo fenômeno
5. **Síntese:** Construir interpretação de ordem superior que integra todos

**Output:** Framework conceitual que explica o fenômeno com base em múltiplas perspectivas

### Template de Extração
```
Pesquisa: [Nome/Autor/Ano]
Tema Central: [O que esta pesquisa está explicando?]
Conceitos-Chave: [3-5 conceitos centrais com definições]
Relações: [Como esses conceitos se relacionam]
Limitações: [O que esta pesquisa NÃO cobre]
Tensão com outras pesquisas: [Onde contradiz outros estudos?]
```

## Framework 2: Cross-Domain Connection (Conexão entre Domínios)

Um dos skills mais valiosos em pesquisa avançada: identificar padrões que se repetem em domínios aparentemente não relacionados.

### Protocolo de Cross-Domain Analysis

**Step 1: Abstração**
Elevar o nível de abstração do achado específico para o padrão geral:
- Específico: "Reddit cresce mais onde há escassez de conteúdo de nicho"
- Abstrato: "Plataformas crescem preenchendo gaps de conteúdo em comunidades subservidas"

**Step 2: Busca Cross-Domain**
Procurar o mesmo padrão em outros domínios:
- "Esse padrão se repete em marketplaces? Em SaaS B2B? Em physical retail?"

**Step 3: Transferência**
Aplicar insights de um domínio para informar estratégia em outro:
- "Como as mecânicas de gamificação de Stack Overflow (reputação progressiva) se aplicariam ao nosso produto?"

### Exemplos de Cross-Domain Insights

| Pattern | Domínio Origem | Transferência |
|---------|---------------|---------------|
| Granovetter's weak ties | Sociologia | Community growth: bridge users entre comunidades têm valor desproporcional |
| Hype Cycle | Gartner/Tech | Qualquer nova categoria de produto passa pelo mesmo ciclo |
| Barabási preferential attachment | Física de redes | Marketing: primeiros clientes em cada nicho atraem os seguintes |
| Long Tail | Economia digital | SEO: volume de long-tail queries supera head terms |
| Death Spiral | Network theory | Qualquer marketplace bilateral pode colapsar se liquidity cai |

## Framework 3: Research Crystallization Engine (Avançado)

Evolução do Insight Crystallization Engine existente para síntese de múltiplas pesquisas.

### Fase 1: Convergência de Findings

Para cada claim relevante, mapear evidências de múltiplas fontes:

```
CLAIM: [Afirmação específica]

Fontes que SUPORTAM:
  - [Fonte A, Tier X]: [Como suporta]
  - [Fonte B, Tier Y]: [Como suporta]

Fontes que CONTRADIZEM:
  - [Fonte C, Tier Z]: [Como contradiz]

Fontes que são NEUTRAS/IRRELEVANTES:
  - [Fonte D]: [Por que não se aplica]

VEREDICTO DE TRIANGULAÇÃO:
  [ ] Forte evidência (3+ fontes Tier 1-2 concordam)
  [ ] Evidência moderada (2+ fontes concordam, sem contradição forte)
  [ ] Evidência fraca (1 fonte ou sources conflitantes)
  [ ] Inconclusivo (evidências contradizem sem resolução)
```

### Fase 2: Padrão de Segunda Ordem

Depois de cristalizar múltiplos findings individuais, buscar o padrão que os conecta:

**Perguntas guias:**
1. "O que esses findings têm em comum?"
2. "Se todos esses findings são verdadeiros, o que DEVE ser verdadeiro que ainda não está explícito?"
3. "Existe uma causa comum que explica múltiplos achados aparentemente não relacionados?"
4. "Onde os achados apontam em direções diferentes — o que essa tensão revela?"

### Fase 3: Síntese Narrativa

Converter o padrão de segunda ordem em narrative que:
- Começa pela conclusão (Pyramid Principle)
- Suporta com os findings cristalizados
- Conecta ao contexto do negócio/decisão
- Culmina em implicações acionáveis

## Framework 4: Competitive Intelligence Synthesis

Para sintetizar inteligência competitiva de múltiplas fontes em visão integrada.

### Battle-Space Map
Síntese visual do espaço competitivo:

```
+-------------------+-------------------+
|                   |                   |
|    CHALLENGERS    |    LEADERS        |
| (alto potencial,  | (alta execução,   |
|  baixa execução)  |  alto potencial)  |
|                   |                   |
+-------------------+-------------------+
|                   |                   |
|    NICHE PLAYERS  |    VISIONARIES    |
| (baixo potencial, | (alto potencial,  |
|  baixa execução)  |  baixa execução)  |
|                   |                   |
+-------------------+-------------------+
     Eixo X: Ability to Execute
     Eixo Y: Completeness of Vision
```

**O que este mapa não diz (armadilhas):**
- Posição hoje ≠ posição amanhã (mercados dinâmicos)
- Quadrante não é destino — é snapshot
- Complementar sempre com análise de velocidade de movimento

### Weak Signal Aggregation
Sintetizar sinais fracos de múltiplas fontes para identificar tendências emergentes antes de serem óbvias:

| Sinal | Fonte | Intensidade | Velocidade | Cross-Domain? |
|-------|-------|-------------|------------|:-------------:|
| [Sinal 1] | [Onde apareceu] | 1-5 | Acelerando/Estável | Sim/Não |

**Threshold para elevar de sinal para tendência:**
- 3+ fontes independentes observam o mesmo sinal, OU
- 1 sinal com intensidade crescente por 3+ períodos consecutivos, OU
- Sinal aparece em 2+ domínios não relacionados

## Framework 5: Narrative Synthesis

Para sintetizar resultados de forma comunicável para audiências não-técnicas.

### Estrutura de Narrativa de Research

**The Hook:** Uma observação contraintuitiva ou surpreendente que captura atenção
> "Empresas com melhor NPS crescem mais lento em alguns segmentos — descobrimos por quê."

**The Stakes:** Por que isso importa para quem lê
> "Isso muda como deveríamos pensar sobre nossa estratégia de retenção para Q3."

**The Evidence:** Findings cristalizados com confidence levels
> Findings organizados do mais forte (HIGH) ao mais fraco (LOW)

**The Mechanism:** O que explica o padrão observado
> "A razão parece ser que..." [mecanismo causal ou correlacional explicado]

**The Implications:** O que fazer diferente
> FINDINGS → IMPLICATIONS → RECOMMENDATIONS no formato padrão da squad

**The Uncertainty:** O que não sabemos, limitações
> "Esta análise não cobre X, Y. Se X for diferente do assumido, a implicação seria Z."

## Ferramentas para Síntese Assistida por IA

### Usando LLMs para Síntese

**Síntese Cross-Source:**
```
Dado os seguintes {N} achados de pesquisas diferentes:
[Lista de findings com fontes]

Identifique:
1. Padrões que aparecem em múltiplas fontes (com evidência)
2. Contradições que precisam de investigação
3. O insight de segunda ordem que emerge da combinação
4. Lacunas que nenhuma fonte cobre
5. Uma síntese de 3-5 frases que captura o essencial
```

**Cross-Domain Pattern Recognition:**
```
O seguinte padrão foi observado em [domínio A]:
[Descrição do padrão]

Pesquise se padrão similar existe em:
- [Domínio B]
- [Domínio C]
- [Domínio D]

Se sim, como as diferenças de contexto afetam a transferibilidade do insight?
```

### Quality Gates para Síntese

Antes de entregar síntese como output final:

- [ ] Todos os findings individuais têm confidence level declarado?
- [ ] A síntese representa fielmente as fontes, sem extrapolação excessiva?
- [ ] Contradições foram explicitamente endereçadas, não ignoradas?
- [ ] O nível de certeza da síntese não excede o das fontes individuais?
- [ ] Limitações e lacunas foram declaradas?
- [ ] O insight de segunda ordem é genuinamente novo ou apenas resumo?
- [ ] Existe pelo menos 1 RECOMMENDATION acionável?
