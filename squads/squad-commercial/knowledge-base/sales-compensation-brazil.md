# Sales Compensation & Incentives — Contexto Brasil

## OTE (On-Target Earnings)

OTE é a remuneração total esperada quando o rep atinge exatamente 100% da quota. Composta de base salary + variable (comissão/bônus).

### Splits Típicos por Papel
| Papel | Base : Variable | Racional |
|-------|----------------|----------|
| SDR/BDR | 70:30 | Mais controle sobre output (atividades) do que outcome (receita) |
| AE (SMB) | 50:50 | Padrão de mercado, incentiva performance forte |
| AE (Mid-Market) | 55:45 | Ciclos médios, equilíbrio estabilidade/incentivo |
| AE (Enterprise) | 60:40 | Ciclos longos (6-18 meses), mais base para estabilidade |
| AM/CSM | 70:30 ou 80:20 | Retention-focused, menos volatilidade aceitável |
| Sales Manager | 60:40 | Combina team performance + individual contribution |
| VP Sales / CRO | 50:50 | Fortemente atrelado ao resultado da organização |

### Regra Quota:OTE Variable
```
Quota deve ser 4-6x o OTE variable

Exemplo:
  OTE variable = R$72K/ano (R$6K/mês)
  Quota = R$288K-432K/ano (R$24-36K/mês)

Se quota < 4x OTE variable: comissão % muito alta, insustentável
Se quota > 6x OTE variable: comissão % muito baixa, desmotiva top performers
```

## Estruturas de Comissão

### Linear
Comissão fixa por real vendido. Simples, previsível.
```
Exemplo: 8% de ACV
Deal de R$100K = R$8K de comissão
Deal de R$50K = R$4K de comissão
```

### Tiered / Accelerator Model (recomendado)
Comissão aumenta progressivamente conforme % de quota atingido. Incentiva overperformance.
```
0-80% quota:   6% de comissão (below target zone)
80-100% quota: 8% de comissão (on-target zone)
100-120% quota: 12% de comissão (accelerator 1)
120-150% quota: 16% de comissão (accelerator 2)
>150% quota:   20% de comissão (super-accelerator)

Por quê accelerators importam:
  Rep com OTE R$10K/mês variable em R$120K quota:
  - Sem accelerator: ganhar R$14K (1.4x) dá mesmo % que R$10K
  - Com accelerator: ganhar R$14K pode significar R$16-18K (1.6-1.8x)
  Top performers (20% do time) geram 80% da receita — retê-los exige accelerators reais
```

### Decelerators (usar com cautela)
Redução de comissão abaixo de certo threshold. Controverso — pode desmotivar reps em períodos ruins.
```
0-50% quota: 4% de comissão
50-80% quota: 6% de comissão
80-100% quota: 8% de comissão (normal)
```

## Quota Setting

### Métodos

**Top-Down:**
1. Board/CEO define meta de ARR para o ano
2. Divide por trimestre/mês
3. Aloca por território/segmento
4. Divide por rep (baseado em ramp, histórico, território)

**Bottom-Up:**
1. Analisa capacidade de cada rep (pipeline histórico, território, maturidade)
2. Soma capacidades individuais
3. Compara com meta da empresa
4. Ajusta (gap analysis)

**Híbrido (melhor prática):**
Faz top-down E bottom-up. Se a diferença é <15%, está calibrado. Se >15%, investigar.

### Regras de Ouro para Quota
- **55-70% do time deve bater quota** em organização saudável. Se <50% batem → quota irreal. Se >80% batem → quota fácil demais, subutilizando potencial
- Dados de 2025: apenas ~35-40% dos reps B2B batem quota consistentemente (RepVue 2024: 39.1%)
- **Ramp quota** para novos reps: 0% no mês 1, 25% mês 2, 50% mês 3, 75% mês 4, 100% a partir do mês 5
- Quota deve ser desafiadora mas atingível — regra: uma pessoa de performance mediana deve atingir com esforço consistente

## SPIFs (Sales Performance Incentive Funds)

Incentivos temporários para comportamentos específicos. Diferentes da comissão regular — são campanhas pontuais.

**Exemplos de SPIFs:**
- "Feche 3 deals de produto X neste mês → bônus de R$5.000"
- "Maior booking de Q1 ganha viagem para o Caribe"
- "Cada upsell >R$50K adicional nesta semana → R$1.000 extra"
- "Demo marcada com C-level → R$500 mesmo sem fechar"

**Regras para SPIFs efetivos:**
- Curta duração (1-4 semanas) — fadiga de SPIF é real
- Objetivo específico e mensurável — sem ambiguidade
- Acessível a todos (não só top performers) — inclusion matters
- Pago rapidamente após atingimento (dentro da mesma semana se possível)
- Não usar SPIFs para compensar quota irreal — não resolve o problema raiz

## Clawbacks

Cláusula que exige devolução de comissão se o cliente cancela antes de período mínimo. Alinha incentivo do vendedor com retenção.

**Tipos:**
| Tipo | Descrição | Quando Usar |
|------|-----------|-------------|
| Full Clawback | 100% da comissão devolvida se churn no período | Ciclos curtos (<90 dias) |
| Pro-Rata | Comissão devolvida proporcionalmente ao tempo restante | Contratos anuais |
| Tiered | 100% se churn 0-3 meses, 50% se 4-6 meses, 0% após 6 meses | Balancear risco/benefício |

**Implementação CLT no Brasil:**
Clawback em CLT é complexo juridicamente. Alternativas:
- Estruturar como bônus condicionado (não como "devolução")
- Pagar 50% da comissão na assinatura, 50% após 3 meses de cliente ativo
- Usar holdback: 20% da comissão retida por 90 dias, liberado se cliente permanecer

## Benefícios CLT para Reps de Vendas (Brasil)

Além do salário, o pacote CLT inclui:
| Benefício | Custo Empresa | Impacto no Rep |
|-----------|--------------|----------------|
| FGTS | 8% do salário | Fundo de garantia ao sair |
| 13° salário | 1/12 por mês | Décimo terceiro |
| Férias + 1/3 | ~13.33% | 30 dias + abono |
| INSS patronal | ~20-28% | Previdência |
| Vale-alimentação | R$30-50/dia (prática) | Alimentação |
| Plano de saúde | R$200-800/pessoa/mês | Saúde |
| PLR (Participação nos Lucros) | Variável | Bônus anual adicional |

**Custo real de um rep de vendas CLT:**
```
Salário base: R$10.000/mês
Encargos trabalhistas (~70% sobre salário): R$7.000/mês
Benefícios (VA, saúde, transporte): R$1.500/mês
Custo total empresa: R$18.500/mês para um rep com R$10K de salário
```

## Gamification & Reconhecimento

Além de comp estruturado, culturas de alta performance usam:
- **Leaderboard** público (pipeline, revenue, activities) — visibilidade cria saudável pressão de pares
- **Ring the Bell** — celebração literal ao fechar deal (física ou virtual no Slack)
- **Deal of the Week** — highlight do melhor deal com lições aprendidas
- **President's Club** — viagem anual para top 10-15% de performers (fortemente motivador)
- **Reconhecimento em all-hands** — VP/CEO reconhecendo publicamente

**Cautelas:**
- Leaderboard pode criar toxicidade se não combinado com cultura de equipe
- Evitar reconhecer apenas resultado (quem fechou o maior deal); reconhecer também processo (melhor discovery, melhor colaboração)
